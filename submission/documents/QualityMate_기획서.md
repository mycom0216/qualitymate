### 검사 이력과 작업표준서를 연계한 RAG 기반 품질관리 지원 시스템

기획서 제출일 2026년 12월 4일
최종 발표일 2026년 12월 30일
작성 기준 2026년 11월 20일 · 개인 프로젝트

### 목표와 대상

검사 담당자가 제품 판정 이력과 관련 재검사 절차를 함께 확인할 수 있도록 한다. C# 서버와 관계형 데이터베이스, 로컬 LLM 기반 RAG를 결합한 실행 가능한 시스템을 개발한다.

### 요구사항

| 구분 | 주요 기능 |

| --- | --- |

| 검사 데이터 | 제품 검색, 최초·현재 판정과 재검사 이력 조회 |

| AI 핵심 | 질문 관련 표준서 검색과 LLM 근거 선택 |

| 데이터 연동 | VisionQC 원본 결과 CSV 가져오기 |

| 정합성 | 재검사 중복 방지, 버전 충돌, CSV 원자적 저장 |

| 발표 | PPT와 실행 시연, 검증 결과 및 한계 설명 |

### 구현 범위

가상 제품 한 종류의 검사 업무를 대상으로 표면 흠집과 이물 의심, 시연용 표준서 4개 절을 사용한다. 실제 공장 적용과 카메라 추론 정확도는 별도 검증이 필요하다.

## 설계와 수행 일정

### 시스템 구성

브라우저에서 C# ASP.NET Core API를 호출하고, API가 SQLite 검사 이력과 표준서 JSON을 조회한다. 로컬 Ollama의 kanana2:3b가 관련 근거 문장을 선택한다. 서버는 선택을 검증하고 원문과 절 ID를 표시한다.

### 기술 선택

C#/.NET 10, HTML/CSS/JavaScript, SQLite, Ollama를 사용한다. 초기 SQL Server 계획은 설치와 시연의 재현성을 고려해 SQLite로 조정했다. 모든 학습 기술을 추가하기보다 검사 이력과 챗봇의 통합에 집중한다.

| 시기 | 수행 내용 |

| --- | --- |

| 11.19 기준 | 통합 실행 버전과 고정 질문 평가 확보 |

| 12.04 | 기획서 제출과 요구사항 최종 확인 |

| 12.05~12.16 | 발표자 환경에서 실행·데이터 점검과 추가 질문 검토 |

| 12.17~12.23 | 현장 용어 검토, 시연 리허설과 오류 보완 |

| 12.24~12.29 | 최종 제출 파일과 발표 환경 확인 |

| 12.30 | PPT 발표, 시스템 시연, 질의응답 |

### 역할과 제출물

개인 프로젝트로 수행한다. 기획·서버·화면·RAG·평가를 통합하며, AI 코딩 도구 활용 내역과 실제 수행 내용은 발표자가 확인한다. 기획서, 결과보고서, PPT, 소스 코드, 실행 패키지를 제출한다.

### 검증과 완료 기준

검사 조회, 재검사 정합성, CSV 연동, 실제 LLM 답변, 근거 없는 질문 처리를 검증한다. 고정 질문 20개로 관련 근거와 인용, 원문 일치, 필요한 답변 구절을 확인한다. 실제 사용자와 생산 현장의 성능은 별도 검증 대상으로 둔다.
